1 Overview

  • lt-package: lt: Lightweight tables via JSON specs and JavaScript

2 Build tables

Create a table and add titles, spanners, row groups, notes, and layout.

  • lt(), lt.default(): Create a table specification
  • lt_footnote(): Add a footnote
  • lt_group(): Define row groups
  • lt_header(): Add a title and subtitle
  • lt_hide(): Hide columns
  • lt_indent(): Indent rows
  • lt_merge(): Merge columns
  • lt_move(): Move columns
  • lt_note(): Add a note
  • lt_spanner(): Add a column spanner

3 Format cells

Format values, dates, and labels, and align and size columns.

  • lt_align(): Set column alignment
  • lt_date(): Format date/time columns
  • lt_format(): Format numeric columns
  • lt_html(): Render column cells as raw HTML
  • lt_label(): Rename column labels
  • lt_sub(): Substitute cell values
  • lt_width(): Set column and table widths

4 Style tables

Style cells and wrap or theme the table with CSS.

  • lt_css(): Attach custom CSS
  • lt_style(): Style cells
  • lt_wrap(): Set attributes on the table’s container

5 Inline graphics

Draw error bars, sparklines, and dot plots inside cells.

  • lt_dotplot(): Draw an inline dot plot in a column
  • lt_errorbar(): Draw an inline error-bar plot in a column
  • lt_sparkline(): Draw an inline sparkline in a column

6 Interactivity

Sort, search, filter, page, resize, and drill down in the browser.

  • lt_interactive(): Enable interactive table features
  • lt_serve(): Serve the rows of an interactive table from a data server
  • lt_viewer(): View a data frame as an interactive table

7 Output and export

Print, serialize, and export tables as HTML, images, or PDF.

  • format.lt_tbl(): Render an lt_tbl to HTML
  • lt_export(): Export an lt table to a file
  • lt_spec(): Extract a table’s render-ready spec
  • print.lt_tbl(): Print an lt_tbl (opens in the viewer or browser)

8 Shiny

Use lt tables as Shiny outputs and inputs.

  • lt_dependency(): HTML dependency for lt tables
  • lt_output(), render_lt(), lt_input(), lt_update(): Shiny bindings for lt

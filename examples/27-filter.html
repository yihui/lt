Column filters

By default each column gets the filter that suits its data: a slider for numbers, a checklist for text with few distinct values. Ask for other widgets by name, or switch a column’s filter off with FALSE.

library(lt)
lt(penguins) |>
  lt_interactive(filter = list("auto", year = FALSE), search = FALSE, pager = 5)

d = penguins[, c("species", "island", "bill_len", "body_mass", "sex")]
lt(d) |>
  lt_interactive(
    filter = list(TRUE, bill_len = "range", species = "checklist", sex = "select"),
    search = FALSE, pager = 5
  )

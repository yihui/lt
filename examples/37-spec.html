The table spec

An lt table is data plus a list of declarative operations. lt_spec() hands you that payload as a list, ready for xfun::tojson(), for another widget to render with LT.render().

library(lt)
tbl = lt(penguins[1:3, 1:4]) |> lt_format(~ bill_len, decimals = 0)
str(lt_spec(tbl), max.level = 2)

#> List of 2
#>  $ data:'data.frame':	3 obs. of  4 variables:
#>   ..$ species : Factor w/ 3 levels "Adelie","Chinstrap",..: 1 1 1
#>   ..$ island  : Factor w/ 3 levels "Biscoe","Dream",..: 3 3 3
#>   ..$ bill_len: num [1:3] 39.1 39.5 40.3
#>   ..$ bill_dep: num [1:3] 18.7 17.4 18
#>  $ ops :List of 1
#>   ..$ :List of 3

xfun::tojson(lt_spec(tbl)$ops)

[
  {
    "type": "fmt_number",
    "columns": ["bill_len"],
    "decimals": 0
  }
]

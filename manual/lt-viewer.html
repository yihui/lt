View a data frame as an interactive table

  • Description
  • Usage
  • Arguments
  • Value
  • Examples

Description

A data viewer: a shorthand for lt_interactive(lt(data, show_types = TRUE), profile = TRUE, hide = NA) with the data expression as the title, made by lt_header(). Each column shows its type and a profile of its values, and the table can be sorted, searched, filtered, paged, resized, and have columns hidden from a menu. Printing the result at the console opens it in the viewer or browser. Use |> lt_header(NULL) to remove the title.

Usage

lt_viewer(data, profile = TRUE, hide = NA, ...)

Arguments

data

A data frame.

profile, hide, ...

Arguments passed to lt_interactive(); profile defaults to TRUE and hide to NA (a column-visibility menu) here.

Value

An lt_tbl object.

Examples

lt_viewer(CO2)

# extra arguments go to lt_interactive(); no profiles, 5 rows per page
lt_viewer(airquality, profile = FALSE, pager = 5)

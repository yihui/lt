Move columns

  • Description
  • Usage
  • Arguments
  • Value
  • Examples

Description

Rearrange column display order without modifying the data frame.

Usage

lt_move(x, columns, after = NULL)

Arguments

x

An lt() object.

columns

Columns to select: a character vector of column names, integer positions, or a one-sided formula. A formula whose right-hand side references the pronoun . (the character vector of column names) is evaluated as a predicate, e.g. ~ endsWith(., "_time") selects all columns whose names end with _time; otherwise the bare names on the right-hand side are used, e.g. ~ x + y.

after

Column name or integer position after which to place the moved columns. Use NULL to move to the start.

Value

x with the column move recorded.

Examples

tbl = lt(mtcars[1:3, 1:5])
# after a column (by name or position)
tbl |> lt_move(~ drat + disp, after = "mpg")

# to the front
tbl |> lt_move(~ disp, after = NULL)

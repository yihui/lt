Description

Add a title and subtitle

Usage

lt_header(x, title = NULL, subtitle = NULL)

Arguments

x

An lt() object.

title

A character scalar. Wrap in I() to treat as raw HTML.

subtitle

A character scalar. Wrap in I() to treat as raw HTML.

Value

x with the header recorded.

Examples

d = ToothGrowth[1:3, ]
lt(d) |> lt_header("Tooth Growth in Guinea Pigs", "First 3 rows")

# a title only; raw HTML (wrap in I())
lt(d) |> lt_header(I("<em>Tooth</em> Growth"))

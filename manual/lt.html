Description

Entry point of the lightweight grammar of tables. Returns an object (a list) that records the data plus a list of table-modifying operations. The object is rendered to HTML by format() (called automatically by the print method).

Usage

lt(data, ...)

## Default S3 method:
lt(data, auto_format = TRUE, auto_label = TRUE, show_types = FALSE, ...)

Arguments

data

A data frame (or anything coercible to one).

...

Arguments passed to methods.

auto_format

Whether to automatically format numeric columns (rounding, thousand separators, percentage detection) and date/time columns (as YYYY-MM-DD or YYYY-MM-DD HH:MM:SS). Set to FALSE to disable for the whole table; use lt_format() on specific columns to disable selectively.

auto_label

Whether to automatically clean column names for display by replacing separators (. and _) with spaces. Set to FALSE to show raw column names.

show_types

Whether to tag each column with its type (e.g., <dbl>, <chr>, <fct>, <date>) under the column labels, like the types printed under a tibble's column names. In an interactive table (see lt_interactive()), the filter controls follow the tags.

Value

A table object that can be piped into lt_*() functions.

HTML in cells

By default all cell values and text (titles, labels, footnotes, ...) are HTML-escaped, so special characters like <, >, and & render as literal text. To emit content as raw HTML instead:

  • For body cells, mark whole columns with lt_html().

  • For a title, subtitle, column label, spanner, footnote, or note, wrap the text in I(). For example, lt_header(x, I("<b>Report</b>")) renders the title as raw HTML, while lt_header(x, "<b>Report</b>") shows the literal <b> tags.

Interactivity

When a cell value has been formatted (e.g., by auto-formatting or lt_format()), the original value is stored in the cell's title attribute and shown as a tooltip on hover. Additionally:

  • Alt + Click on a table toggles display of all raw values in that table.

  • Alt + Double-Click on a table toggles raw values globally (all tables on the page).

Raw values are shown as (value) after the formatted text, highlighted with a light yellow background.

Missing values

By default, missing (NA) cells display an em dash (—) so they are not confused with empty strings. Change the table-wide default with the lt.missing global option, e.g. options(lt.missing = "n/a"); set it to the empty string (options(lt.missing = "")) to leave NA cells blank. Use lt_sub() with missing = to override the text for specific columns.

Repeated data in litedown::fuse() documents

A document often shows several tables built from the same data, e.g., one data frame with different columns, groups, or formatting in each table. To keep the output file small, lt() writes the data into the document only once; the other tables just point to that copy instead of repeating the data. This happens automatically when the document is rendered by litedown::fuse(), including documents that include child documents.

Sharing saves space except for tiny data: a data frame with roughly 15 cells or fewer (e.g., 5 rows by 3 columns) is about as small as the pointer to it, so sharing it gains nothing and may add a few bytes. For anything larger, the saving grows with the size of the data and the number of tables using it. To share only data frames above a certain size, set the lt.share_size global option (in bytes, as reported by utils::object.size()), e.g., options(lt.share_size = 1e4); smaller data is then written into each table. Use options(lt.share_size = Inf) to turn sharing off.

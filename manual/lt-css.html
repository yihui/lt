Attach custom CSS

  • Description
  • Usage
  • Arguments
  • Value
  • Examples

Description

Add user-supplied stylesheets or inline rules that render after the built-in CSS, so rules can override the defaults. Inline rules are scoped to the table; stylesheets are page-wide, as usual.

Usage

lt_css(x, ...)

Arguments

x

An lt() object.

...

Unnamed arguments are stylesheet paths or URLs. A bare filename (no directory component) that does not exist in the working directory is resolved against the stylesheets shipped with lt, so e.g. lt_css(x, "lt-plot.css") adds the stylesheet for inline plots.

Named arguments define inline CSS rules that apply to this table only (other tables on the page are unaffected). Names are selectors (e.g., .high, td.highlight) and values are either a CSS string or a named list of properties: lt_css(x, .high = "background: #eee") or lt_css(x, .high = list(background = "#eee")). The selectors and rules can also be given as a single list(selectors, rules) of two parallel vectors (see lt_label()).

Value

x with the stylesheets recorded.

Examples

d = trees[1:4, ]
# rules for this table only: a selector and a CSS string or list
lt(d) |>
  lt_style(~ Girth, test = "v => v > 8.5", class = "high") |>
  lt_css(.high = list(background = "#cfc", fontWeight = "bold"), td = "color: #06c")

# a stylesheet (here one shipped with lt)
lt(d) |> lt_css("lt-plot.css")

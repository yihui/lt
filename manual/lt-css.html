Attach custom CSS

  • Description
  • Usage
  • Arguments
  • Value
  • Examples

Description

Add user-supplied stylesheets or inline rules that render after the built-in CSS, so rules can override the defaults.

Usage

lt_css(x, ...)

Arguments

x

An lt() object.

...

Unnamed arguments are stylesheet paths or URLs. A bare filename (no directory component) that does not exist in the working directory is resolved against the stylesheets shipped with lt, so e.g. lt_css(x, "lt-plot.css") adds the stylesheet for inline plots.

Named arguments define inline CSS rules scoped to .lt-table. Names are selectors (e.g., .high, td.highlight) and values are either a CSS string or a named list of properties: lt_css(x, .high = "background: #eee") or lt_css(x, .high = list(background = "#eee")). The selectors and rules can also be given as a single list(selectors, rules) of two parallel vectors (see lt_label()).

Value

x with the stylesheets recorded.

Examples

tbl = lt(head(mtcars))
tbl |>
  lt_style("mpg", test = "v => v > 20", class = "high") |>
  lt_css(.high = list(background = "#cfc", fontWeight = "bold"))

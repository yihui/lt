Add summary rows

Description

Append rows that summarize the data: one after each group, a grand summary for the whole table, or both. A summary is whatever fn computes from a data frame, so a sum, a weighted mean, or a count are all the same call.

Usage

lt_summary(
  x,
  fn = NULL,
  cols = NULL,
  by = NULL,
  label = NULL,
  grand = NULL,
  label_col = NULL,
  data_fn = NULL
)

Arguments

x

An lt() object.

fn

A function (or its name, such as "sum" or "max") of one column that returns its summary, applied to each column in cols; or a named list of such functions, one per column. It is called with na.rm = TRUE when it accepts that argument. Give exactly one of fn and data_fn.

cols

The columns that fn summarizes, when it is a single function. Numeric columns by default.

by

A column name or one-sided formula (e.g., ~grp) to summarize each group of. Leave it NULL for a grand summary only.

label

The text of a group summary row, shown in label_col. By default, the capitalized name of fn if it is a name (e.g., "Sum"), else "Subtotal" ("Total" without by).

grand

The text of the grand summary row at the bottom; FALSE for none. With by, "All" by default. Without by, the one summary row is the grand row, labeled label.

label_col

The column that shows label and grand; the first column other than by by default.

data_fn

A function that takes a data frame (the rows of one group, or of the whole table) and returns the summary values as a named list or data frame of one row. Columns it does not return are left empty. Use this to combine several columns, e.g., a weighted mean.

Details

Summary rows are shown in bold. A group summary closes its group. The grand summary sits at the bottom of the table. In an interactive table (see lt_interactive()), summary rows are not sorted, filtered, or counted as matches: a group summary follows its group's rows through sorting and disappears with the group when a filter removes all of its rows, while the grand summary stays put. The values are computed once, from all rows, and do not change as the table is filtered.

Call lt_summary() before functions that refer to rows by position (e.g., lt_style() with rows), because summary rows shift the positions of the rows after them. Combine it with lt_group() on the same column as by so that each group's rows stay together.

Value

x with the summary rows added.

Examples

d = data.frame(
  grp = c("A", "A", "B", "B"), item = c("x", "y", "x", "y"),
  n = c(10, 30, 20, 40), rate = c(0.12, 0.34, 0.56, 0.78)
)
# a function (or its name) of a column, for every numeric column
lt(d) |> lt_summary("sum", by = ~ grp)
# a grand summary only, with a different function per column
lt(d) |> lt_summary(list(n = sum, rate = "mean"))
# a function of the whole data frame, for a weighted mean
total = function(x) list(n = sum(x$n), rate = weighted.mean(x$rate, x$n))
lt(d) |>
  lt_summary(data_fn = total, by = ~ grp) |>
  lt_group(~ grp, sep = TRUE) |>
  lt_format(~ rate, percent = TRUE, decimals = 1)

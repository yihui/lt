Description

Use lt tables in Shiny apps, as outputs or as inputs.

Usage

lt_output(outputId, ...)

render_lt(expr, env = parent.frame(), quoted = FALSE)

lt_input(inputId, x, label = NULL, columns = NULL)

lt_update(session, inputId, x, columns = NULL)

Arguments

outputId

Output variable name to read the table from.

...

Reserved for future use.

expr

An expression that returns an lt() object.

env

Environment in which to evaluate expr.

quoted

Whether expr is already quoted.

inputId

The input slot that will be used to access the value.

x

An lt() table, a data frame, or a matrix (the latter two shown without automatic number formatting, so cells display the values they hold). The server gets the edited table back as a matrix if x is one, and as a data frame otherwise.

label

Display label for the input, or NULL for no label.

columns

Names of the editable columns; all columns by default. For lt_update(), the current editable columns are kept by default.

session

The session object passed to the Shiny server function.

Details

lt_output() creates a UI placeholder; render_lt() supplies the table spec from the server. Together they render an lt() table as a custom Shiny output.

lt_input() shows a table whose body cells can be edited in the browser; the edited table is available to the server as a data frame in input[[inputId]]. lt_update() replaces the table from the server (e.g., to add or remove rows, or to reset the edits). Numeric columns accept only numbers (an empty cell is NA); other columns hold text. Press Enter to commit a cell and move down a row. Editing does not work with row groups shown as spanning cells, nor with lt_interactive(), which reorders rows.

Value

lt_output() and lt_input() return a Shiny UI element; render_lt() returns a render function; lt_update() is called for its side effect.

Examples

if (interactive()) {
library(shiny)
ui = fluidPage(
  lt_output("tbl"),
  lt_input("m", head(mtcars[, 1:3]), "Edit the cells:"),
  verbatimTextOutput("out")
)
server = function(input, output) {
  output$tbl = render_lt(lt(head(mtcars)) |> lt_header("Motor Trend"))
  output$out = renderPrint(input$m)
}
shinyApp(ui, server)
}

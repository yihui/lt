**lt** builds lightweight tables from a data frame and a few pipeable verbs.
This page is only a taste: three cheat tables, one minimal
example, and pointers to the [book](../book/) for the details.

## The cheat sheet {#sec:cheatsheet}

Three cheat tables give an overview, one each for static tables, interactive
tables, and inline plots. Each is self-documenting: functions in this package
build it, and each function's name is placed where that function acts.

```{r}
library(lt)
```

### Static tables {#sec:cheat-static}

The title reads `lt_header(title = ...)` because `lt_header()` put it there;
every column header is the name of the function that shaped that column; the
row-group label is `lt_group()`; the footnote text is `lt_footnote()`; and so on.

```{r}
d = data.frame(
  Grp   = paste("Group", c("A", "A", "B", "B")),
  Label = c("<a href='#sec:cheatsheet'>lt(): make a table</a>",
            "lt_indent(): child A", "lt_indent(): child B", "lt_style() + lt_css()"),
  Fmt   = c(1234567.89, -0.51234, Inf, -Inf),
  Sub   = c(0, NA, 3.14, 0.0002),
  Date  = as.Date(c("2024-01-15", "2024-02-20", "2024-03-25", "2024-04-30")),
  Align = c(1, 22, 333, 4),
  Est   = c("0.6", "0.8", "0.5", "0.9"),
  CI    = c("(0.4, 0.8)", "(0.6, 1.0)", "(0.2, 0.7)", "(0.7, 1.1)")
)

tbl_static = lt(d, auto_format = FALSE) |>
  lt_group(~ Grp) |>
  lt_header(title = "lt_header(title = ...)", subtitle = "lt_header(subtitle = ...)") |>
  lt_merge(~ Est + CI, pattern = "{1} {2}") |>
  lt_spanner(`lt_spanner()` ~ Fmt + Sub) |>
  lt_label(
    Grp = "lt_group()", Label = "lt_label(old = new, ...)", Fmt = "lt_format()",
    Sub = "lt_sub()", Date = "lt_date()", Align = "lt_align()", Est = "lt_merge()"
  ) |>
  lt_html(~ Label) |>
  lt_align(~ Align, "center") |>
  lt_width(Align = "6em") |>
  lt_format(~ Fmt, decimals = 1, big_mark = ",") |>
  lt_date(~ Date, options = list(month = "short", day = "numeric", timeZone = "UTC")) |>
  lt_sub(~ Sub, missing = "n/a", zero = "—", small = 0.01, small_text = "< 0.01") |>
  lt_indent(c(2, 3), level = 1) |>
  lt_style(~ Label, rows = 4L, class = "highlight") |>
  lt_css(.highlight = list(fontWeight = "bold", color = "orange")) |>
  lt_footnote("lt_footnote() can add a footnote anywhere.", "title") |>
  lt_footnote(I("Wrap text in <code>I()</code> for raw HTML."), "column", ~ Label) |>
  lt_footnote("lt_width() sets column widths.", "column", ~ Align) |>
  lt_footnote("lt_move() can reorder columns as desired.", "column", ~ Est) |>
  lt_note("lt_note() — and lt_export() saves this table to HTML/PDF/PNG/RTF.")
tbl_static
```

### Interactive tables {#sec:cheat-interactive}

`lt_interactive()` adds sorting, search, filters, and paging in the browser.
Each row below names an argument and tells you how to try it on this table:
click a header to sort, type `Kind is Layout` in the search box, or pick a value
from a filter.

```{r}
d = data.frame(
  Argument = c("sort", "search", "filter", "pager", "resize", "hide", "detail",
               "profile", "download"),
  Kind = c("Find rows", "Find rows", "Find rows", "Layout", "Layout", "Layout",
           "Layout", "Inspect", "Output"),
  Default = c("TRUE", "TRUE", "auto", "10, 25, 50, Inf", "TRUE", "NULL", "NULL",
              "FALSE", "FALSE"),
  Try = c("click a header", "type a query", "pick a value", "change page size",
          "drag a header edge", "hide columns", "expand a row",
          "summarize columns", "save CSV or RTF"),
  Popularity = c(95, 64, 61, 36, 20, 16, 12, 8, 5)
)

tbl_interactive = lt(d) |>
  lt_header("lt_interactive(...)", "Click, type, and pick") |>
  lt_interactive(pager = c(5, 10, Inf), hide = NA, profile = TRUE, download = TRUE) |>
  lt_note("lt_viewer() and lt_serve() view and serve big data.")
tbl_interactive
```

### Inline plots {#sec:cheat-plots}

Each plotting function draws in the cell of the column that carries its name.

```{r}
d = data.frame(
  Study = c("A", "B", "C"),
  Eff = c(0.1, -0.3, 0.4), Lo = c(-0.1, -0.4, 0.2), Hi = c(0.3, -0.2, 0.6),
  Temp = I(list(c(-3, 1, 6, 12), c(14, 18, 28, 31), c(19, 18, 15, 15))),
  Rain = I(list(c(49, 47, 53, 60), c(5, 4, 0, 0), c(8, 2, 1, 1))),
  Before = c(3.1, 3.4, 3.0), After = c(3.2, 4.1, 5.2)
)

tbl_plots = lt(d) |>
  lt_header("Plot functions in lt") |>
  lt_errorbar(Eff ~ Lo + Hi, ref = 0) |>
  lt_sparkline(~ Temp) |>
  lt_sparkline(~ Rain, type = "bar", color = "limegreen") |>
  lt_dotplot(~ Before + After, color = TRUE) |>
  lt_spanner(`lt_sparkline()` ~ Temp + Rain) |>
  lt_label(
    Eff = "lt_errorbar()", Temp = "line", Rain = "bar", Before = "lt_dotplot()"
  )
tbl_plots
```

03. Migrating from gt to lt (source: 03-gt.Rmd) ►

---
title: "Migrating from gt to lt"
output:
  html:
    meta:
      css: ["@default", "@callout"]
      js: ["@callout"]
---

```{css, echo = FALSE}
table:not([class]) { width: 100%; }
```

This is the short version of the guide for users coming from
[**gt**](https://gt.rstudio.com). We deeply appreciate **gt**'s pioneering work:
**lt** owes much of its design vocabulary — headers, spanners, row groups,
footnotes — to the ground **gt** broke. **lt** targets HTML output only, and in
exchange keeps its dependencies and its runtime tiny: **gt** pulls in ~54
recursive dependencies, whereas **lt** depends only on **xfun**.

::: {.callout-tip data-legend="gt > < lt"}
A happy coincidence fits the spirit of this trade-off: in the comparison
operators **gt** is *greater than* and **lt** is *less than* — **lt** does
deliberately less.
:::

## The most common calls

| gt | lt |
|------------------------------------|--------------------------------------------|
| `gt(x)` | `lt(x)` |
| `gt(x, groupname_col = "col")` | `lt(x) \|> lt_group(~ col, sep = TRUE)` |
| `tab_header(title=, subtitle=)` | `lt_header(title=, subtitle=)` |
| `tab_spanner(label=, columns=)` | `lt_spanner(label=, columns=)` |
| `cols_label(a = "A")` | `lt_label(a = "A")` |
| `tab_footnote(footnote, cells_body(col, rows))` | `lt_footnote(text, "body", columns, rows)` |
| `tab_source_note(source_note=)` | `lt_note(text)` |
| `fmt_number(columns=, decimals=)` | `lt_format(columns, decimals=)` |
| `sub_missing()` / `sub_zero()` | `lt_sub(missing=, zero=)` |
| `opt_interactive()` | `lt_interactive()` |
| `gtsave(file=)` | `lt_export(file=)` |

## What to watch for

-   Columns are selected by name or position (or a one-sided formula), not
    tidy-select helpers.
-   Interactivity is one function, `lt_interactive()`, not a separate step.
-   Footnotes (`lt_footnote()`) and source notes (`lt_note()`) are two functions.
-   Row groups render as rowspan cells or separator rows (`sep =`).
-   Extend `lt()` with S3 methods rather than a new generic.
-   Styling rarely needs CSS: try `lt_style()` first.

The [complete guide](../book/#chp:gt) in the book has the full function mapping,
the differences in detail, and a runnable example. If you maintain a package that
ships tables, see [Building on lt](../book/#chp:extend).

05. Column labels (source: 05-label.Rmd) ►

---
title: Column labels
---

Column names are cleaned for display (`.` and `_` become spaces). Override any of them with `lt_label()`, or show the raw names with `auto_label = FALSE`.

```{r}
library(lt)
tbl = lt(head(iris))
tbl
lt(head(iris), auto_label = FALSE)
tbl |> lt_label(Sepal.Length = "Length (cm)", Sepal.Width = "Width (cm)")
```

06. Alignment and widths (source: 06-align-width.Rmd) ►

---
title: Alignment and widths
---

Numbers align right and text left by default. `lt_align()` changes that, and `lt_width()` sets column widths; an unnamed width sizes the whole table.

```{r}
library(lt)
lt(head(mtcars[, 1:5])) |>
  lt_align(~ mpg + cyl, "center") |>
  lt_width("80%", mpg = "8em", cyl = "5em")
```

---

```{r}
library(lt)
d = data.frame(

lt(d, show_types = TRUE)
```

2 Format cells

Automatic formatting, numbers, dates, and substitutions.

08. Automatic formatting (source: 08-auto-format.Rmd) ►

---
title: Automatic formatting
---

By default `lt()` formats numbers for you: about four significant digits, thin-space thousands separators, a typographic minus, percent for columns named like `*_pct`, and a hands-off policy for years. Set `auto_format = FALSE` to see the raw values.

```{r}
library(lt)
d = data.frame(
  Year = c(2020, 2021, 2022),
  Revenue = c(1234567.89, 2345678.12, -3456.789),
  Margin_pct = c(0.1234, 0.0567, 0.2345)
)
lt(d)
lt(d, auto_format = FALSE)
```

09. Number formatting (source: 09-number.Rmd) ►

---
title: Number formatting
---

`lt_format()` controls decimals (or significant digits), the thousands mark, percent, and a prefix or suffix.

```{r}
library(lt)
d = data.frame(
  Item = c("Widget", "Gadget", "Doohickey"),
  Revenue = c(1234567.891, 987654.321, 246913.57),
  Margin = c(0.1234, 0.0567, 0.2345),
  Mass = c(0.00054858, 1.00727647, 4.00150618),
  Weight = c(1250, 340.5, 89.12)
)
lt(d) |>
  lt_format(~ Revenue, decimals = 0, big_mark = ",", prefix = "$") |>
  lt_format(~ Margin, decimals = 1, percent = TRUE) |>
  lt_format(~ Mass, sig_digits = 3) |>
  lt_format(~ Weight, decimals = 1, suffix = " kg")
```

10. Dates and times (source: 10-date.Rmd) ►

---
title: Dates and times
---

`lt_date()` formats dates and date-times in the browser with `Intl.DateTimeFormat`, so `locale` and `options` work as in JavaScript. Pass `timeZone = "UTC"` to keep a date from shifting with the reader's time zone.

```{r}
library(lt)
d = data.frame(
  Event = c("Launch", "Update", "Release"),
  Date = as.Date(c("2024-01-15", "2024-06-30", "2024-12-01")),
  Time = as.POSIXct(c("2024-01-15 09:30:00", "2024-06-30 17:45:00",
    "2024-12-01 12:00:00"), tz = "UTC")
)
lt(d) |>
  lt_date(~ Date, locale = "fr-FR", options = list(
    weekday = "long", day = "numeric", month = "long", timeZone = "UTC"
  )) |>
  lt_date(~ Time, locale = "en-US", options = list(
    hour = "2-digit", minute = "2-digit", timeZone = "UTC"
  ))
```

11. Substituting values (source: 11-sub.Rmd) ►

---
title: Substituting values
---

`lt_sub()` swaps special values for friendlier text: missing values, zeros, and numbers too small to show. `Inf` and `-Inf` already print as ∞ and −∞.

```{r}
library(lt)
d = data.frame(
  Metric = c("HR", "p-value", "Events", "Rate", "Upper bound"),
  Value = c(0.62, 0.0003, 0, NA, Inf)
)
lt(d) |>
  lt_format(~ Value, decimals = 2) |>
  lt_sub(~ Value, missing = "n/a", zero = "—", small = 0.001, small_text = "< 0.001")
```

3 Shape the table

Merge, span, move, hide, group, and indent.

12. Merging columns (source: 12-merge.Rmd) ►

---
title: Merging columns
---

`lt_merge()` folds several columns into one with a pattern. Wrap a part in `<<` and `>>` to drop it when a referenced value is missing.

```{r}
library(lt)
d = data.frame(
  endpoint = c("Primary", "Secondary", "Tertiary"),
  est = c(0.61, 0.79, 0.45),
  lo = c(0.40, 0.57, NA),
  hi = c(0.82, 1.01, NA)
)
lt(d) |>
  lt_format(~ est + lo + hi, decimals = 2) |>
  lt_merge(~ est + lo + hi, pattern = "{1}<< ({2}, {3})>>") |>
  lt_label(est = "Estimate (95% CI)")
```

13. Column spanners (source: 13-spanner.Rmd) ►

---
title: Column spanners
---

A spanner is a label over a run of columns. Name it with a formula, or call `lt_spanner()` with no arguments to infer spanners from shared prefixes such as `Sepal.` and `Petal.`.

```{r}
library(lt)
tbl = lt(head(iris))
tbl |> lt_spanner(Sepal ~ Sepal.Length + Sepal.Width)
tbl |> lt_spanner()
```

14. Moving and hiding columns (source: 14-move-hide.Rmd) ►

---
title: Moving and hiding columns
---

`lt_move()` reorders columns (`after = NULL` moves them to the front), and `lt_hide()` drops columns from view while their data stays in the table for anything that reads whole rows, such as an interactive row detail.

```{r}
library(lt)
tbl = lt(head(iris))
tbl |> lt_move(~ Species, after = NULL)
tbl |> lt_hide(~ Petal.Length + Petal.Width)
```

15. Row groups (source: 15-group.Rmd) ►

---
title: Row groups
---

`lt_group()` partitions rows by the values of a column (or several). Short labels become spanning cells on the left; long ones switch to full-width separator rows, which `sep` can force either way.

```{r}
library(lt)
d = data.frame(
  Region = c("East", "East", "East", "West", "West", "West"),
  State = c("NY", "NY", "MA", "WA", "WA", "OR"),
  City = c("New York", "Buffalo", "Boston", "Seattle", "Spokane", "Portland"),
  Population = c(8336817, 278349, 675647, 737015, 228989, 652503)
)
lt(d) |> lt_group(~ Region) |> lt_header("Cities by region")
lt(d) |> lt_group(~ Region + State)
lt(d) |> lt_group(~ Region, sep = TRUE)
```

16. Manual groups and group order (source: 16-group-manual.Rmd) ►

---
title: Manual groups and group order
---

Groups need not come from a column: name the rows yourself, by row numbers or by a condition on the data. Pass group labels to a second `lt_group()` call to put the groups in the order you like.

```{r}
library(lt)
tbl = lt(head(mtcars[, 1:4], 6))
tbl |> lt_group("First three" = 1:3, "Last three" = 4:6)

# a one-sided formula is evaluated in the data
tbl |> lt_group(Efficient = ~ mpg > 20, Thirsty = ~ mpg <= 20)

d = data.frame(
  arm = c("Placebo", "Placebo", "Treatment", "Treatment"),
  stat = c("n", "Mean", "n", "Mean"),
  value = c(30, 4.2, 31, 6.8)
)
lt(d) |>
  lt_group(~ arm, sep = TRUE) |>
  lt_group("Treatment", "Placebo")
```

17. Row indentation (source: 17-indent.Rmd) ►

---
title: Row indentation
---

`lt_indent()` nests rows to show hierarchy, one level per step.

```{r}
library(lt)
d = data.frame(
  label = c("Any AE", "Cardiac", "Tachycardia", "Bradycardia", "GI", "Nausea"),
  n_pct = c("45 (67%)", "30 (45%)", "15 (22%)", "18 (27%)", "20 (30%)", "12 (18%)")
)
lt(d) |>
  lt_header("Adverse events", "Safety population") |>
  lt_indent(c(2, 5), level = 1) |>
  lt_indent(c(3, 4, 6), level = 2)
```

4 Notes and HTML

Footnotes, source notes, and raw HTML.

18. Footnotes (source: 18-footnote.Rmd) ►

---
title: Footnotes
---

`lt_footnote()` attaches a numbered footnote to the title, subtitle, a column label, a spanner, a row group, or specific body cells.

```{r}
library(lt)
d = data.frame(
  Arm   = c("Treatment", "Treatment", "Control", "Control"),
  Stat  = c("n", "Mean", "n", "Mean"),
  Value = c(31, 6.8, 30, 4.2),
  SE    = c(NA, 0.42, NA, 0.38)
)
lt(d) |>
  lt_group(~ Arm) |>
  lt_header(title = "Study Results", subtitle = "Two arms") |>
  lt_spanner(Summary ~ Value + SE) |>
  lt_footnote("Source: simulated trial data.", "title") |>
  lt_footnote("Intention-to-treat population.", "subtitle") |>
  lt_footnote("Standard error of the mean.", "column", ~ SE) |>
  lt_footnote("Per-arm summary statistics.", "spanner", ~ Summary) |>
  lt_footnote("Received active drug.", "group", ~ Treatment) |>
  lt_footnote("SE is undefined for counts.", "body", ~ SE, rows = c(1, 3))
```

19. Source notes (source: 19-note.Rmd) ►

---
title: Source notes
---

`lt_note()` adds an unnumbered note to the footer, below any footnotes. It is the place for sources and caveats.

```{r}
library(lt)
lt(head(mtcars[, 1:5])) |>
  lt_note("Data from the 1974 Motor Trend US magazine.")
```

20. HTML in cells and labels (source: 20-html.Rmd) ►

---
title: HTML in cells and labels
---

Everything is HTML-escaped by default. Mark whole columns as HTML with `lt_html()`, and wrap any other text (titles, labels, notes) in `I()`.

```{r}
library(lt)
d = data.frame(
  Package = c(
    "<a href='https://cran.r-project.org/package=xfun'>xfun</a>",
    "<a href='https://cran.r-project.org/package=litedown'>litedown</a>"
  ),
  Mood = c("<b style='color:#090'>stable</b>", "<i>always evolving</i>")
)
lt(d) |>
  lt_html(~ Package + Mood) |>
  lt_header(I("Packages <sup>&#9733;</sup>")) |>
  lt_label(Package = I("Name<sup>*</sup>")) |>
  lt_note(I("See <a href='https://yihui.org/'>the author</a>."))
```

5 Style

Cell styles, CSS, and table wrappers.

21. Styling cells (source: 21-style.Rmd) ►

---
title: Styling cells
---

`lt_style()` styles chosen cells with inline CSS shortcuts. With `test`, a JavaScript predicate decides which cells qualify, and a `class` plus `lt_css()` keeps the rules in one place.

```{r}
library(lt)
d = data.frame(
  Endpoint = c("Primary", "Secondary", "Exploratory"),
  HR = c(0.62, 0.79, 1.05),
  P = c(0.001, 0.042, 0.38)
)
lt(d) |>
  lt_format(~ HR + P, decimals = 3) |>
  lt_style(~ Endpoint, rows = 1, bold = TRUE, color = "#06c") |>
  lt_style(~ HR, test = "v => v < 1", class = "good") |>
  lt_style(~ P, test = "v => v < 0.05", class = "sig") |>
  lt_css(.good = list(color = "green"), .sig = list(fontWeight = "bold"))
```

22. Scoping CSS to one table (source: 22-css-wrap.Rmd) ►

---
title: Scoping CSS to one table
---

`lt_wrap()` sets attributes on the table's container. Tag it with a class and your stylesheet can target that table alone.

```{r}
library(lt)
lt(head(mtcars[, 1:5], 4)) |> lt_wrap(class = "striped")
```

```{css}
.striped tbody tr:nth-child(even) td { background: #f2f6ff; }
```

6 Inline graphics

Error bars, sparklines, and dot plots.

23. Error bars (source: 23-errorbar.Rmd) ►

---
title: Error bars
---

`lt_errorbar()` turns `estimate ~ lower + upper` into a tiny forest plot on a shared scale. `ref` draws a reference line, `axis` a shared axis, and `into` puts the plot in its own column.

```{r}
library(lt)
d = data.frame(
  Term = c("Age", "Dose", "Baseline", "Sex"),
  Est  = c(0.12, -0.34, 0.45, -0.08),
  Lo   = c(-0.05, -0.52, 0.21, -0.29),
  Hi   = c(0.29, -0.16, 0.69, 0.13)
)
lt(d) |>
  lt_errorbar(Est ~ Lo + Hi, ref = 0, into = "Forest", hide = FALSE,
    axis = "Effect (95% CI)")
```

24. Sparklines (source: 24-sparkline.Rmd) ►

---
title: Sparklines
---

`lt_sparkline()` draws a small line or bar chart per row from a list-column, or from several columns read across the row.

```{r}
library(lt)
d = data.frame(City = c("Oslo", "Cairo", "Lima"))
d$Temp = list(c(-3, -2, 1, 6, 12, 16), c(14, 15, 18, 23, 28, 31), c(19, 19, 18, 16, 15, 15))
d$Rain = list(c(49, 36, 47, 41, 53, 60), c(5, 4, 4, 1, 0, 0), c(8, 4, 2, 1, 1, 1))
lt(d) |>
  lt_sparkline(~ Temp) |>
  lt_sparkline(~ Rain, type = "bar", color = "#4caf50")
```

25. Dot plots (source: 25-dotplot.Rmd) ►

---
title: Dot plots
---

`lt_dotplot()` places one dot per column on a scale shared across them, perfect for before-and-after comparisons. `color = TRUE` adds a legend; `stagger = TRUE` separates dots that land on nearly the same value.

```{r}
library(lt)
d = data.frame(
  Group = c("Control", "Low", "High"),
  Before = c(3.1, 3.4, 3.0), After = c(3.2, 4.1, 5.2)
)
lt(d) |>
```

35. Editable tables in Shiny (source: 35-shiny-input.Rmd) ►

---
title: Editable tables in Shiny
---

`lt_input()` is a table whose cells you can edit in the browser; `input$m` is the edited data frame. `lt_update()` replaces it from the server.

```{r, eval = FALSE}
library(shiny)
library(lt)
d = data.frame(Time = c(12, 24), Rate = c(0.8, 0.6), Note = c("a", "b"))
ui = fluidPage(
  lt_input("m", d, label = "Edit the cells:", columns = ~ Time + Rate),
  actionButton("add", "Add row"),
  verbatimTextOutput("out")
)
server = function(input, output, session) {
  output$out = renderPrint(input$m)
  observeEvent(input$add, lt_update(session, "m", rbind(input$m, NA)))
}
shinyApp(ui, server)
```

```{js, echo = FALSE}
// lt.js is deferred: queue LT.build() calls until it loads (other chapters

(window.LT ??= {}).build ??= function(spec) {
```

The R package is a thin layer over a small JavaScript runtime, which you can
use without R. Add the stylesheet and script to an HTML page:

``` html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@xiee/utils/css/lt.min.css">
<script src="https://cdn.jsdelivr.net/npm/@xiee/utils/js/lt.min.js"></script>
```

Then call `LT.build(spec)` from an inline `<script>` wherever a table should
appear. The spec is plain JSON: `data` by column, plus `ops` that format, label,
and decorate it. This one is made without any R code:

```{js}
LT.build({
  data: {
    Item: ["Widget", "Gadget", "Doohickey"],
    Price: [1234.5, 678.9, 42],
    Margin: [0.1234, 0.0567, 0.2345]
  },
  header: { title: "Price list", subtitle: "Straight from JavaScript" },
  ops: [
    { type: "fmt_number", columns: ["Price"], decimals: 2, big_mark: ",", prefix: "$" },
    { type: "fmt_number", columns: ["Margin"], decimals: 1, percent: true }
  ],
  interactive: { pager: false, filter: false }
});
```

For the full story (every op, the `interactive` options, `LT.render()`, the
controller for driving a table from outside, and the protocol for serving rows
from your own server), see the chapter on the [JavaScript
runtime](../book/#chp:js) in the book. Two small examples to start from:
[a table from JavaScript](38-js-build.html) and [driving a table from
outside](39-js-control.html).

39. Driving a table from outside (source: 39-js-control.Rmd) ►

---
title: Driving a table from outside
---

```{r assets, echo = FALSE, results = 'asis'}
# link the runtime (lt-plot loads before the core script)
cat(
  lt:::css_block(c('lt.css', 'lt-plot.css', 'lt-interactive.css'), inline = FALSE),
  lt:::js_block(c('lt-plot.js', 'lt.js', 'lt-interactive.js'), inline = FALSE),
  sep = '\n'
)
```

`LT.render(element, spec)` builds a table whenever you like, and returns it. Every interactive table carries a controller at `el._lt`, so outside widgets can filter it: here a `<select>` keeps one species.

```{r, echo = FALSE}
iris5 = iris[c(1, 2, 51, 52, 101, 102), ]
```

```{js, fill = xfun::tojson}
const iris = `{ iris5 }`;
```

```{js}
const host = document.createElement("div");
document.currentScript.after(host);
addEventListener("load", () => {
  const t = LT.render(host, { data: iris, interactive: { search: false, pager: [5] } });
  const sel = document.createElement("select");
  sel.innerHTML = '<option value="">All species</option>' +
    [...new Set(t._lt.spec.data.Species)].map(s => `<option>${s}</option>`).join("");
  sel.onchange = () => t._lt.filter(
    "species", sel.value ? row => row.Species === sel.value : null
  );
  t.before(sel);
});
```
